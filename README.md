## アプリ概要
DAILY PLANは、1日の予定を時間順に整理し、日々の行動を視覚化するためのシンプルなスケジュール管理アプリです。

規則正しい生活習慣を意識して継続するために、毎日の起床・食事・就寝などの予定をあらかじめ可視化できるツールとして制作しました。

予定を立てること自体が負担にならないよう、入力項目を「時間・タスク・補足」の3項目に絞り、必要な情報を一目で確認できるシンプルな設計にしています。

## 主な機能
- タスクの追加
- 編集
- 削除
- 時間順の自動並び替え
- localStorageによるデータ保存
- 必須項目の入力チェック

## 使用技術
- HTML
- CSS
- JavaScript
- Web Storage API (localStorage)

## 工夫した点
- 深夜0:00〜4:59の予定を前日の続きとして扱い、1日の生活スケジュールとして自然な順番になるようソート処理を実装
- localStorageを利用し、ページを再読み込みしても登録内容が保持されるよう実装
- editingIndexで編集対象を管理し、同じ入力フォームから新規追加と編集の両方を行えるよう実装
- 日常的に使用しやすいよう、必要な情報に絞ったシンプルなUIを設計
