# DAILY PLAN

1日の予定を時間順に整理し、時間配分を意識した生活をサポートするシンプルなスケジュール管理アプリです。

## 制作背景・目的

日々の生活リズムを整え、時間を意識して行動するためのツールとして制作しました。

既存のスケジュール管理アプリやToDoアプリは、多機能である一方、自身の利用目的に対しては機能が過剰で、画面上の情報量も多いと感じていました。

今回重視したのは、複雑なタスクや長期的な予定の管理ではなく、起床・食事・就寝など、日常的に繰り返す行動の時間を決め、1日の流れを把握できることです。
また、生活に必要な行動とその時間配分を可視化することで、ほかの活動に使える時間も意識しやすくすることを目指しました。

そこで、1日単位のスケジュールを簡単に作成・確認できることを基本方針とし、必要な機能を絞って設計しました。

## 要件整理・仕様設計

利用者である自身の目的を整理し、「予定を登録する負担を減らすこと」「1日の流れを直感的に把握できること」を優先しました。

- 簡単に予定を登録したい  
  → 入力項目を「時間・タスク・補足」の3つに限定

- 1日の流れを把握したい  
  → 登録した予定を時間順に自動で並び替え

- 日常的に繰り返し使いたい  
  → localStorageで登録内容をブラウザに保存

- 操作を複雑にしたくない  
  → 新規追加と編集に共通の入力フォームを使用

- スマートフォンでも予定を確認したい  
  → 画面サイズに合わせた表示に対応

また、各予定に優先順位をつけて管理する用途ではなかったため、優先度設定やカテゴリ分類等は設けず、利用目的に合う情報と操作に絞ることを重視しました。

## UI・UX設計

### 情報の優先順位

1日の予定を素早く把握できるよう、タスク名を目立たせ、補足情報は補助的な位置づけで表示しています。
予定のタイトルを簡潔にすることで、一覧を見たときに行動の流れを把握しやすくすることを意識しました。

### 継続して使いやすいデザイン

毎日開くアプリだからこそ、スケジュール管理への義務感や圧迫感をできるだけ抑えたいと考えました。
彩度を抑えたペールトーンや自身が心地よく感じるフォントを選び、視覚的な刺激の少ない画面を目指しました。

### 利用場面に合わせた表示

PCを使用していない時でも1日の流れを俯瞰できるよう、スマートフォン表示に対応しました。
画面幅に合わせて予定一覧と入力エリアの配置を調整しています。

## 主な機能

- 予定の追加・編集・削除
- 時間順の自動並び替え（午前2時を区切りとして、深夜の予定も1日の流れに沿って表示）
- `localStorage`によるデータ保存
- 必須項目の入力チェック
- 画面幅に応じたレスポンシブ表示

## 使用技術

- HTML
- CSS（CSS Grid、メディアクエリなど）
- JavaScript
- Web Storage API（`localStorage`）
